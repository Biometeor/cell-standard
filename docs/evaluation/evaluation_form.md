# 数据集自评评分表

> **用途**：用户对自己的整个数据集/项目进行综合自评，评估数据质量和元信息完整度。
> **推荐使用**：[⬇️ 下载 Excel 自评表](数据集自评评分表.xlsx)

---

## Excel 结构说明

| Sheet | 内容 |
| :--- | :--- |
| **项目基本信息** | 项目名称、数据类型、样本规模、负责人等基础信息 |
| **元信息完整度自评** | 逐项检查 5 个核心字段 + 16 个推荐字段是否已填报，自动计算完整度 |
| **单文件 QC 分布** | 统计各等级文件数量，确定基础质量等级（A/B/C） |
| **综合评级计算** | 根据"基础质量 + 元信息评级"交叉矩阵，得出最终等级 |
| **评级标准参考** | 完整的评级规则说明，填写前查阅 |

## 自评流程

1. **项目基本信息** — 填写项目基本信息和统计指标
2. **元信息完整度自评** — 在"已填报"列标记 ✓ 或 ✗，自动计算核心完整度与辅助完整度，得出元信息评级（优/良/差）
3. **单文件 QC 分布** — 填入各等级文件数量，参考规则确定基础质量等级（A/B/C）
4. **综合评级计算** — 将基础质量等级与元信息评级交叉，得出最终评级（1-4 级）

## 评级流程

```
单文件QC评级 → 基础质量定级(A/B/C)
                                    → 交叉矩阵 → 最终等级(1-4级)
元信息填报率 → 元信息评级(优/良/差)
```

详细规则见 [项目数据评估打分](../project_evaluation.md) 文档。
