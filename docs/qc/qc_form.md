# 数据文件质控填写表

> **用途**：用户递交数据时填写/对照质控指标，确保数据质量达标。
> **推荐使用**：[⬇️ 下载 Excel 填写模板](数据质控填写表.xlsx)（指标为列名，每行填一个样本）

---

## Excel 结构说明

| Sheet | 内容 |
| :--- | :--- |
| **阈值参考** | 所有指标的定义、阈值（1/2/3 级）、单位，填写前查阅 |
| **scRNA-seq 填写区** | scRNA-seq / snRNA-seq 指标的填写表格 |
| **Spatial 填写区** | 空间转录组指标的填写表格 |
| **scATAC-seq 填写区** | scATAC-seq 指标的填写表格 |
| **评级汇总** | 所有样本的最终评级汇总 |

## 填写说明

1. **阈值参考** Sheet 列出了每个指标的可接受范围，先查阅再填写。
2. 在对应的填写区 Sheet 中，**每行填一个样本**，指标名作为列名。
3. **绿色背景列** = 必填指标，**白色背景列** = 可选/参考指标。
4. 填写后参照阈值参考 Sheet 中的标准，在评级汇总 Sheet 中给出每个样本的综合评级。
5. 评级规则：取所有必填指标中的**最低等级**（木桶效应），全部可选指标达 1 级可提升 1 级。

## 评级标准参考

| 等级 | 定义 | 业务解释 |
| :---: | :--- | :--- |
| **1 级** | 优质 | 可直接用于高水平研究或 AI 训练 |
| **2 级** | 合格 | 可用于常规分析 |
| **3 级** | 让步接受 | 数据可用性受限，需谨慎使用 |
| **4 级** | 不合格 | 不建议使用 |
